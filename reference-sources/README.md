# Reference Sources Dropzone

このフォルダは、会話で参照させたいドキュメントや参考リポジトリを一時的に置くための場所です。

## 使い方
- `reference-sources/` の直下に参考リポジトリや資料を展開してください（zipを解凍するだけでOK）。
- このフォルダ内は `.gitignore` で README と `.gitignore` 以外を無視するようにしているので、大量のドキュメントを入れても Git には載りません。
- 後でRAGなどの取り込み処理を追加するときは、ここをデータ入力元にする想定です。

## メモ
- 大きなファイルを入れる場合はストレージ残量に注意してください。
- もし別の場所に置きたい場合は、このREADMEか `.gitignore` を好みのディレクトリに移してもらって構いません。
